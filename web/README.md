# Deep Focus public website

This is an isolated Next.js public-content app. It does not change the Expo
mobile runtime and does not implement the authenticated Account Portal.

Node.js `>=20.9.0` is required. Exact package versions are pinned in
`package.json`; `package-lock.json` is generated by the official npm CLI. Run
`npm run dev`, `npm test`, `npm run typecheck`, `npm run lint` and `npm run build`
from this directory after dependencies are installed.

Public copy is deliberately a development preview: no unverified download,
feature availability, price, contact channel, legal policy, accessibility claim,
or release date is advertised. Account, billing and private data routes are not
implemented here. Legal/commercial/age-policy pages remain publication-gated.
No analytics, ad SDK, external image, form submission, auth cookie, or provider
credential is configured. Hosting, domains, production content approval and
deployment remain separately gated.
