APPROVAL: Owner's expanded V1 implementation authorization, 2026-10-07. Only the named local development implementation is in scope; no production data/migration, deployment or account deletion was performed.  
BEHAVIOR: User sees a confirmation before deletion. SQLite checks `(owner_id,id,updated_at)` inside one transaction, unlinks matching sessions by setting `task_id` to NULL, preserves the existing `task_name` snapshot (or fills it from the task title only when absent), then deletes the owner-scoped task.  
FAILURE/RECOVERY: Cancel leaves task untouched; stale revision returns conflict and requires reload plus fresh confirmation; SQL failure rolls back both unlink and deletion; repeat delete is harmless; no internal DB details are rendered.
